# Service Business Dashboard

A business intelligence dashboard for service-based businesses.
Pulls live data from Supabase and displays it in a clean.
Designed to work for any service business.

## Features

- **Revenue tracking**
- **Cost & profitability** — material cost per service matched against real bookings
- **Per-service breakdown** — profit, margin %, average cost and average profit per service
- **Tomorrow's agenda** — automatic panel showing the next day's appointments, times and clients
- **Appointments table** — sortable by client, service, date, price or status, with cost and profit per row
- **Charts** — monthly revenue vs cost vs profit, bookings per month, peak hours, most requested services

## Tech Stack

- React + Vite
- Recharts
- Supabase (PostgreSQL)
- Deployed on Vercel
