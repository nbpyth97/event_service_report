# Google Calendar Dashboard

A simple React + Vite dashboard to read data from your Supabase tables.

## Setup

1. Open a terminal in `dashboard`
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open the local URL shown by Vite.

## Available tables
- `events`
- `clients`
- `organizers`

## Notes
- The app uses `@supabase/supabase-js` and environment variables from `.env`
- If your Supabase project credentials change, update `.env`
